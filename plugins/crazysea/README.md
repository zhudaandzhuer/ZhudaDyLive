# 疯狂海世界

`plugin.crazysea` v1.1.0 是猪大直播的互动直播插件：主播盖楼求下班，观众可以送出石头、炸弹、海水过滤器和其他互动事件改变场景。

## 内容

- `plugin.json`：插件 manifest 与场景事件、参数和礼物规则。
- `index.html`、`app.js`、`style.css`：可直接部署的插件运行时。
- `assets/sea-mark.svg`：本地品牌资源。
- `BUILD-RECORD.json`、`安装说明.txt`：v1.1.0 发布记录和安装说明。

该目录来自桌面项目的 v1.1.0 发布工作区，未纳入设计稿、测试截图和临时构建目录。
