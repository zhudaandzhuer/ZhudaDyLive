# 场景工作台

打开应用直接进入场景工作台。抖音登录与直播连接按需进行；未登录时仍可搭建场景、导入素材、安装本机插件和测试画面。

主界面使用黑白灰配色。左侧两个分页为直播观测、插件区；右侧常驻场景搭建／场景测试。切换左侧分页不重建右侧来源。设置菜单提供抖音账号、直播连接、诊断报告和使用教学。

## 场景与来源插件

主程序负责场景库、观测与范式直播数据、权限、图层生命周期、进度、版本及输出。插件提供来源的外观与参数／动作描述。特殊商业需求维持插件形式，不区分个人版或公会版。

## 操作

- 首页「图层」标题旁的「添加来源」插入已安装且激活的插件来源。内附解锁挑战、缝纫机挑战、直播任务单、文字、图片、视频及色块。空场景只显示设置的背景。
- 来源选择在同一个滚动区域按「基础场景」「插件」分组展示，不需要切换分类分页；所有互动玩法使用统一的游戏图标，图层列表沿用同一图标。
- 在中央拖曳移动、右下角缩放，或在右侧输入位置、尺寸、旋转、不透明度。左侧图层列表上方覆盖下方：拖动名称或拖动柄调整层级，插入线标记放置位置，靠近列表边缘自动滚动；按 Esc 或在列表外松开可取消。也可选中图层后按 Alt + ↑/↓ 微调。每行提供显示、锁定和删除按钮，删除前会确认；右侧保留拷贝和来源版本信息。调整顺序会同步画布与输出，并自动保存。
- 右侧「尺寸调整」可选「等比缩放」或「调整布局」。等比缩放保留来源的布局尺寸，拖动角点、修改宽高或输入「缩放 %」时，文字、图标、间距整体缩放；布局模式改变来源容器并重新排版。新玩法说明和文字默认等比缩放，旧来源保持原模式。缩放设置会随场景自动保存。
- 场景名称旁设置直版／横版／自订尺寸及背景。改尺寸保留各图层的绝对位置与大小，可用「填满场景」适配。
- 交互图层加入场景后自动进入待命状态，统一等待场景级礼物事件；同一礼物可分别触发多个图层的不同动作。插件不再区分试玩和正式运行，也不要求主播逐个启动玩法。
- 「场景测试」提供全局事件面板：选择礼物与数量后，一次事件会分发给场内所有图层，各图层按自己的礼物映射决定动作；全局热键同样只绑定礼物与数量。测试事件与真实直播事件走同一套宿主分发、去重、变量和完成特效流程。
- 隐藏不影响事件处理；互动图层不会被完成特效或单个回合归零关闭，继续等待下一次全局事件。下播、停止连接、切换直播间或重新开启工作台时，宿主会清除上一场的直播间、回合和事件去重身份，再让所有插件重新待命。
- 中央「场景搭建／场景测试」分页只切换工作台内的编辑与干净预览，不自动弹出窗口。需要直播伴侣截取时，在预览栏点击「打开输出窗口」。手动开启的独立输出持续同步编辑；搭建和预览栏均可点击「关闭输出窗口」，也可在输出窗口按 Esc 关闭。分页切换不重载来源或重设进度。独立输出不含工具列、编辑框、错误提示或网址列。绿幕色键为 `#00FF00`；透明 alpha 是否能截取由平台与直播软件决定。

### 输出清晰度

搭建区和内嵌预览按可用空间缩放；独立输出按场景原始像素渲染，例如直版 1080×1920、横版 1920×1080。输出不再先缩到屏幕可用范围或 70%，不依赖高清插件。窗口按显示器 DPI 换算原生尺寸和页面缩放，使场景一像素对应捕捉一像素；跨屏或显示缩放改变时重新换算。分数 DPI 的原生窗口尺寸向上取整，边缘可能多出不足一个系统逻辑像素，避免裁切。

输出使用独立内存会话，共用已校验的插件与媒体协议；编辑器放大／缩小不改变输出。输出固定尺寸，不支持拖小、最大化或 F11 全屏，以免被系统重新缩放。场景比屏幕大时窗口可超出屏幕，完整画面通过窗口捕捉取得；日常编辑使用工作台内预览。直播软件应按相同尺寸捕捉和输出，原始低分辨率图片／视频放大仍受素材自身细节限制。

锁链 1.2.0 改为两侧纵向绑链与下半部随机交错，中间宽度 68%、上半部高度 50% 留给人脸。路径本身绕开此区域，三款材质、横竖版与不同数量使用相同规则；新增绑合、断裂、熔化与火花也受同一保护区域约束。每点仍逐根绘制，4,200 点有 4,200 根独立路径。现有场景暂停后点击「套用已安装的新版来源」，保留进度、映射、热键与布局；固定的旧版本不会被改写。

## 场景库

点击顶部「场景名称 ⌄」打开场景库，可新建、将当前场景另存为、重命名、切换及删除，最多保存 100 个场景。每个场景独立保存尺寸、背景、图层顺序、素材、玩法主题、参数、礼物映射和说明图层。编辑持续自动保存，重开恢复最后使用的场景；旧单场景自动成为库中的第一个场景。

另存为复制配置，生成新的场景及图层 ID，自动重建说明层到玩法实例的绑定，运行进度从未启动开始。本机媒体使用同一份内容缓存。切换会关闭旧输出并结束旧场景交互；回到原场景可查看原进度，需主动重新开始，避免不同主播接收彼此的事件。删除只允许非当前场景，保留本机素材和插件。插件安装和抖音登录都属于工作台本机操作。

## 玩法说明

选择玩法图层，在右侧点击「添加玩法说明」。说明独立成层，自动读取该实例的礼物映射，包含礼物名称、图标、动作名称和数量。玩法尚未启动也可显示；完整礼物列表会自动适配说明区域高度，超出时整体缩小。修改映射会同步到搭建、预览及输出。可设置标题、横向／纵向排列、颜色、字号和底板，并独立移动、缩放、隐藏与复制。

删除绑定玩法后，说明停止输出，在编辑器提示重新选择；右侧「绑定玩法」可更换目标。只按图层 ID 绑定，不会自动绑定同一插件的另一个玩法。

### 独立状态面板

锁链插件 1.3.0 将数量、模式、进度条和礼物提示拆成「解锁挑战 · 状态面板」独立图层，锁链来源只输出锁链特效。新增玩法时自动配套，旧场景从早期版本升级时只迁移一次，保留原回合、数量、主题、映射、热键和图层布局。面板默认 720×240，字号适合手机预览，可独立移动、等比放大缩小、隐藏、锁定和调整层级；标题、计数名称、默认提示、颜色、底板透明度和显示项可实时调整。

在玩法属性点击「编辑状态面板」快速选中，删除面板后可点击「添加状态面板」恢复。面板只读取绑定实例的数据，不重复计算礼物、播放锁链音效或完成特效；隐藏面板不停止玩法。复制玩法会连同已配置面板复制并重建绑定，另存场景也会重建绑定。目标被删除时面板停止输出，可在属性中重新选择同插件的兼容玩法。场景保存及重开保留面板位置、缩放和绑定。

插件通过 `statusSourceId` 声明配套来源，配套来源声明 `kind: "status"` 与 `targetSourceId`。状态来源保持静态，不声明交互、计数器或完成特效；工作台将目标的 runtime、game、events 与 variables 只读提供给它，面板自身保留独立参数和几何信息。此能力需要工作台 0.2.0。

宿主从官方礼物目录取得图标，仅为当前场景用到的礼物按需缓存，最多并发 3 个，单个不超过 1 MB。只接受可信 HTTPS CDN 和 PNG／JPEG／GIF／WebP，禁止跳转与脚本图像；来源通过本机媒体协议读取，离线沿用缓存。目录无图标或下载失败显示礼物占位图和名称，配置仍可使用。

## 一致性与保存

`SceneManager` 使用本机 SQLite 保存 `scene:state`，包含当前场景文档及各图层 runtime；`scene:library` 保存其他场景。场景切换、另存和库更新在同一 SQLite 事务提交。布局有 revision，过期修改会拒绝并要求重试。拖曳及缩放在放开时保存。取色器在 `input` 时立即更新并保存，通过按场景和图层合并的串行队列保留最后一次颜色；不要求失焦，搭建与独立输出同步。`settings` 命令只合并改变的参数，校验当前场景及锁定状态，避免旧颜色覆盖其他参数。媒体导入后拷贝到 `userData/scene-assets/`，按 SHA-256 命名；原档搬走不影响场景。

直播礼物先由 `LocalStore.ingest` 去重、范式连击增量，与观测数据、各图层状态及持久化事件 ID 一起交易提交。互动图层加入场景后即待命，首个匹配礼物才创建新的回合。所有图层在同一场景级分发中按自己的映射响应；下播、停止连接、切换直播间或重开工作台会清理上一场的礼物／事件去重记录，避免新房间复用旧消息 ID 后被误判重复。插件不可用时仅停止对应来源，观测仍可用。

预览与输出订阅同一快照；来源 iframe 没有修改进度的 API。全局事件测试与真实礼物使用相同的 requestId 去重和动作计算，重试不会重复计算。初次加载以现有状态作为基准，不重播历史特效。视频使用宿主的累积播放时间，暂停／继续或重开输出时同步位置。

初次升级会将旧版目前回合迁移一次，保留数量、兼容主题及礼物映射，先暂停。旧历史数据保留。无法加载的场景保存于 `scene:recovery:<唯一标识>`，显示复原提示，不覆盖原始副本。

## 来源声明

在一般插件 manifest 增加 `sceneSources`，每个来源有自己的入口、预设尺寸、参数、动作、映射及主题。类型与运行期验证在 `packages/contracts/src/scenes.ts`。

```json
{
  "workspace": false,
  "permissions": ["scene-events"],
  "sceneSources": [
    {
      "id": "chain",
      "name": "解锁挑战",
      "description": "观众透过礼物加锁或解锁",
      "entry": "index.html",
      "width": 1080,
      "height": 1920,
      "runtime": "interactive",
      "parameters": [],
      "events": [
        {
          "id": "unlock",
          "label": "解开锁链",
          "description": "逐根断裂熔化",
          "operation": "subtract",
          "amountLabel": "解开根数",
          "unit": "根",
          "min": 1,
          "max": 1000000,
          "default": 10
        }
      ],
      "rules": [
        { "giftId": "2001", "giftName": "玫瑰", "eventId": "unlock", "amount": 10, "delta": -10 }
      ],
      "themes": [],
      "counter": { "initial": "4000", "label": "锁链根数" }
    }
  ]
}
```

`runtime` 可为 `static`、`interactive` 或 `media`；未指定时，有动作为交互来源，否则为静态来源。媒体来源显示播放／暂停控制。动作以 `add`／`subtract`／`effect` 描述，数量由宿主换算，`counter` 可选。无计数器的特效来源不会在数量为零时自动结束。

`workspace: true` 可让同时提供场景来源的插件仍有「打开管理」及侧栏入口，供未来皮套管理等功能使用。只有来源的插件使用 `workspace: false`。没有来源的一般工具插件沿用管理页与既有 SDK。

参数支持 `text`、`number`、`color`、`boolean`、`select`、`image`、`video`。参数定义含 key、label、default；数字可声明 min／max，菜单提供 options。宿主自动产生设置界面。图档限制 10 MB，支持 PNG／JPEG／WebP／GIF；视频限制 100 MB，支持 MP4／WebM，不支持的编码仍可能无法播放。媒体字段只接受宿主选取并导入的 `zhuda-scene://media/<hash>.<ext>`，不接受任意网络或文件路径。

所有来源入口必须在 ZIP 文件清单中；声明动作须要求 `scene-events` 权限。

## 插件自定义玩法说明

普通玩法声明 `instructionSourceId` 指向同一个插件中的说明来源，该来源声明 `kind: "instructions"`，使用静态 runtime，事件、规则为空，不提供计数器。宿主优先使用插件自己的说明外观，未声明时使用内置「场景基本素材」通用说明。说明入口仍须包含在签名文件清单中。

`scene.subscribe` 的 `state.instructions` 提供绑定目标的 `targetLayerId`、`targetName`、`theme` 与 `mappings`。每个映射含 `giftId`、`giftName`、本机 `icon`（可为 null）、`eventId`、`label`、`description`、`operation`、`amount`、`unit`。这些数据独立于运行回合，插件只负责排版，不能在说明层中运算或更改游戏进度。

## 来源 SDK

### 通用完成特效与实时参数

玩法来源声明 `completion: { text: "下班啦！", color: "#efc982" }`，工作台自动生成「完成特效」参数组，提供文案、颜色、3–5 秒展示时长、烟火与总开关。锁链和缝纫机共用工作台的播放器，不再在插件里用完成状态维持常驻提示。文案、颜色和开关即时生效；时长在下一次完成时采样。

宿主在每次完成时保存独立的 `completionId`、`completedAt` 与 `completionDurationMs`，时间到后移除文字和烟火。位置调整、参数更新及重开输出不会重播过期事件；新输出只展示有效事件的剩余部分。加工作量恢复玩法时，宿主撤掉完成标识，所有画面立即取消完成特效，玩法继续接收事件。再次归零产生新的完成标识；完成后的重复减量不重复庆祝。

插件可在 `parameters` 自定义、增加或删除字段，使用可选的 `group` 显示独立参数组。声明 `live: true` 的参数通过增量设置即时保存，即使图层锁定也能调整；锁定仍阻止画布选取、移动和缩放。插件升级时保留仍支持的参数值，删除不再声明的参数，并为新增参数补上默认值。完成特效的五个 `completion*` 参数名由工作台保留。

`scene.subscribe` 同时提供 `state.completion`（id、at、durationMs），自定义渲染插件可据此判断完成事件；使用通用完成效果的插件无需自行计时或监听礼物取消。

```ts
import { scene } from '@zhuda/plugin-sdk';

const unsubscribe = scene.subscribe((state) => {
  // layerId、name、settings、theme、status、mode、playbackTime
  // game：宿主处理后的回合、最近动作与进度
  // events：最近 30 笔范式事件
  // instructions：仅说明来源收到，含 targetLayerId、targetName、theme、mappings
  render(state);
});
const stopEvents = scene.onEvent((event) => {
  // gift / message / status，live / demo，直播间、时间与清理过的数据。
  // 初次加载以当前历史为基准，之后每个事件只通知一次。
  playEffect(event);
});
```

来源 iframe 只打开 `allow-scripts`，没有 Node、preload、同源或登录数据。来源 SDK 是唯读状态通道；`studioPlugin` 保存／文件夹／外部链接 API 由独立管理页提供，不在输出来源中运行。宿主确认消息来源是目前 iframe，处理就绪通知及可选的声音中继。来源可渲染动作与事件，不应在预览和输出中各自修改游戏进度。添加宿主运算类型时须扩充版本化合约与 reducer。

场景来源 iframe 使用独立的默认色彩模式，避免深色工作台与透明插件的色彩模式不匹配而产生白底。礼物说明图层的空白区域保持透明，可透出下层玩法和视频；“显示底板”只控制单条礼物的底板。

宿主通过可选 `SceneFrameState.renderScale` 提供场景与来源的总显示缩放。Canvas 插件应使用 `devicePixelRatio × renderScale` 分配画布像素，避免把缩小的手机／编辑预览仍按整张高清输出重复绘制；逻辑坐标和逐根数量保持不变。完整输出的缩放为 1。旧宿主未提供时按 1 兼容。

解锁挑战 1.2.5 提供「锁链特效」参数：绑合默认 1.1 秒、消融默认 2.4 秒，调整对下一次动画生效。连续礼物不再加速正在播放的动画；每根变化仍独立绘制，静止时缓存画面，批量特效预计算几何与粒子方向并减少重复粒子绘制。

1.3.0 将实际清空交由逐根动画完成，不再因权威数字提前归零而隐藏静态锁链层。连续「100 → 40 → 0」时，待消融的 40 根保留到下一段动画；静态层与动态层在同一绘制帧交接，避免清空后重新出现。刚绑上锁链就快速清零的情况采用相同规则。

## 发行与版本

来源与工具都使用本机插件 ZIP。`npm run build` 产生 `client/dist/bundled-plugins/` 内附来源及 `.local/packages/plugin-examples/` 示例 ZIP；开发者将新版本 ZIP 放进工作台显示的插件区即可使用。

场景固定 `pluginId + pluginVersion + sourceId`。插件区扫描到同一 ID 的更高版本 ZIP 时自动安装并保留旧版本，运行中的图层继续使用原版本，暂停后可应用新版；不兼容时保留旧版。禁用或移除插件使相关图层不可用，场景配置与进度仍保留。

## 验证

### 手机局域网预览

画布上方的「手机预览」按需开启只读局域网服务并生成二维码。手机与电脑连接同一 Wi-Fi 或局域网后，扫码并用浏览器打开，无需安装手机应用。画面使用当前场景的相同比例，自动适配手机横竖屏，支持隐藏工具栏及实时同步图片、视频、文字、玩法事件和完成特效；不依赖独立输出窗口开启。视频静音自动播放，格式解码能力取决于手机浏览器。玩法音效需在手机点按“开启声音”，全屏模式也保留声音开关。切到后台、断线或结束分享立即停声，返回后可重新开启；刷新后需再次点按，不补播历史声音。

多网卡可在二维码面板选择电脑地址。网络有客户端隔离或防火墙阻止本地访问时，需要连接可互通的网络并允许本地网络访问。关闭二维码面板继续分享；「停止分享」或退出工作台立即撤销链接，重新开启生成新链接。分享不会跨重启自动开启。

手机只接收当前可见且可用的场景图层，不提供采集登录、插件管理、场景写入、插件本地文件夹或其他场景素材的接口。链接带随机会话标识，素材访问仍校验当前场景引用和已安装来源版本。SSE 推送变化、重连获取最新快照，并限制连接数与发送积压。手机与电脑时间有偏差时会校正动画时间。

手机预览测试使用隔离数据和无预载桥的浏览器窗口，验证二维码、手机尺寸的横竖屏、素材加载、文字更新、媒体连续性、事件、完成特效打断、重连和撤销。此自动检查不等同于真实 iOS／Android 扫码验证。

`npm test` 验证多实例、交易回滚、去重、暂停与恢复、版本、迁移及素材边界。Electron 实机验收应针对目标平台打包文件执行，确认教学、来源插入、拖曳缩放、预览／输出一致、图片与视频、直横版及完整进程重启。

目标平台打包文件需验证原生捕捉尺寸、四角、单像素线条、Canvas、文字与视频、编辑器缩放隔离、横竖版切换及关闭重开；模拟不等同于 Windows 实机和直播伴侣捕捉验收。

## 界面语言

客户端、原生菜单、教学及内置来源统一为简体中文；用户自定义文字、文件名、弹幕与观众昵称保持原样。`npm run locale:check` 检查系统文案，`npm test` 覆盖图片／视频的导入边界和渲染逻辑。

## 缝纫机与任务单

缝纫机提供三种主题，独立针数和倒计时，可映射增加／减少针数、翻倍、清空开门、时间加减／翻倍及过载特效。倒计时以宿主运行时间计时，暂停、重开输出与重启不会重置；时间归零或针数清空完成挑战。栅栏、针头、飞轮、缝线与粒子由插件绘制，支持直横版和柔和特效。

缝纫机 1.1.0 将针数表现为待加工订单：追加订单送入新布卷，翻倍追加一批布料；加速缝制才启动机针、飞轮与送布，出布端留下缝线并叠放成品。无加工事件时机器待机。最后一单完成后才收走成品、打开牢门；已经完成的回合重开直接恢复结果。宿主即时结算数量，机身数字以 BigInt 插值跟随最新权威值，连续礼物衔接加工且尾部动画最多 3.6 秒。暂停取消表现并对齐数量，继续时不重播旧加工；时间和过载事件不会消耗布料。旧礼物事件 ID 保持兼容。

缝纫机 1.2.0 采用每点一块的独立折叠布料：30 点绘制 30 块，4,200 点绘制 4,200 块。布料从机器输入侧的台面逐层堆高，数量多时扩展到另一侧；布堆向高处压实，中央保持留空，不像锁链散布全屏。每块布按身份生成稳定的层位、轻微偏转、织纹、折边和配色，重开及横竖版仍保持数量。追加订单从上方落进布堆，缝制从布堆抽取实际减少的布块卷向机针；附带冲击波、机身震动和线头粒子。待缝布料不再使用固定五卷或透明度近似。静止画面缓存，极大数量分帧绘制，可随最新状态中止，不设固定显示数量上限。暂停或重开对齐当前数量，不重播旧布料动画。

所有玩法的完成状态与交互生命周期独立：`runtime.status` 保持 `running`，`game.round.status` 标记 `won`，归零不关闭来源、不停止礼物或观测路由。新的全局事件在同一实例和回合内恢复 `running`，可重复完成。下播、换房或来源不可用才会重置或停止交互。完成时冻结倒计时；新订单恢复剩余时间，若倒计时已经耗尽则自动使用来源配置的时长。旧版本保存的终止完成态按重开规则迁移为可继续的待命态。

缝纫机 1.2.1 在最后一块缝完后展示下班特效，继续等候礼物；新布料到来自动收起下班提示、合上栅栏并恢复布堆，动画中途收到订单也能接续。锁链在归零后同样继续接收绑链事件。画布上的锁定图层不参与指针命中，点击可以穿过它选择底层；左侧列表仍可选中并解除锁定。

### 通用热键与手动补触发

在「场景测试」的全局事件面板选择礼物与数量直接触发，或打开「全局热键设置」录制电脑组合键。热键绑定场景礼物，不绑定单一图层；一次按键会让所有已加入的玩法按各自映射响应。支持 F1–F24，或 Ctrl、Alt、Shift、Command 与字母、数字、方向键等组合。Mac 录制的 Command 以 `CommandOrControl` 保存，迁移 Windows 时对应 Ctrl。

配置随场景自动保存。当前场景的全局热键在工作台运行时注册，切到直播助手等其他应用仍可触发。下播或切换场景会清理旧房间事件身份并重新注册当前场景热键。录制期间临时注销全部热键，避免配置时误触发；关闭配置恢复，窗口失焦或渲染进程退出也会释放录制状态。重复组合键会全部标记冲突，系统占用或注册失败会显示原因；修改组合键后保存可重新注册。

全局测试事件走与礼物相同的计数、变量、完成和特效逻辑。事件保留来源为 `global`／`global-hotkey` 的状态记录，不伪造观众礼物或增加送礼人数。每次触发使用独立请求 ID 去重，并校验当前场景、运行状态、礼物映射和数量；旧回调不能操作新场景。连续按键带 250ms 节流。

目标平台打包文件需在独立用户数据目录验证热键录制、系统注册、按钮补触发、录制注销、暂停恢复及场景保存；自动化合成键盘事件不等同于操作系统全局热键输入。

任务插件 1.1.1 提供送礼人数、点赞、关注与心愿四种独立透明进度条。每条都是单独图层，可拖动、缩放、删除，名称、目标、颜色和百分比均可实时配置；无总标题、底板和运行状态。观测进度条也提供加减与归零动作，支持通用补触发和热键。旧任务单升级后可点击「拆分为独立进度条」，保留统计、目标、主题、礼物映射与热键，并继承观众去重记录。新增来源仅展示四条独立进度条，旧组合来源保留兼容。送礼人数按本轮观测到的用户 ID 去重；点赞只累计协议明确给出的消息增量，关注只接受关注事件并按用户 ID 去重，不把直播间累计总量当作新增量。统计始于本图层开始／继续之后，不代表直播间完整历史。任务单默认等比缩放，全部进度在宿主持久化，输出关闭后继续计算。

来源可声明 `variables`（key、label、initial、可选的数字参数 parameter）以及 `observations`（kind 为 like／follow／gift-sender／gift，target 为变量 key）。变量可使用 `clock: "countdown"` 和 `finishAtZero: true`。动作可声明 `mutation: { target, operation, value? }`，target 为变量 key 或计数器 remaining，operation 为 add／subtract／multiply／set；未指定 value 时使用映射的 amount。旧动作及签章包保持兼容。`state.variables` 仅提供宿主计算后的显示值，插件仍不能写入状态。

整蛊舞台已从来源、插件区和执行入口下架；已有本机数据保留供恢复。新插件直接放入本机插件区安装。

插件可声明 `splitSources: [{ sourceId, x, y }]`，将旧组合来源拆分为同一版本插件中的独立来源。宿主在版本校验与事务内执行，保持原缩放、旋转和可见性，按变量和动作声明分配状态、设置、映射与热键。首个子来源保留原图层 ID，其他子来源生成独立回合；图层锁定、版本冲突或超过图层上限时整次拒绝。

## 0.3.0 编辑、搬迁与恢复

工具栏提供撤销／重做，快捷键为 Ctrl／Command + Z、Ctrl／Command + Shift + Z 或 Ctrl + Y。每个场景保存最近 30 次编辑历史；连续取色会合并。撤销只恢复配置，不回滚期间收到的礼物和当前计数。被删除后恢复的玩法保持暂停，避免自动重新接收礼物。切换插件来源版本也可撤销；版本改变后需手动继续。

场景库可导出／导入 `.zhudascene`：包含场景配置、本机图片／视频及固定插件版本信息，最多 300 MB。包不包含抖音登录、插件二进制、运行进度或直播记录。导入生成新场景及图层 ID，重建绑定，热键默认停用。旧场景仍保存在库中；缺少的插件版本显示不可用，不自动安装或执行包中代码。导入验证失败不覆盖当前场景。

通用展示部件声明 `kind: "view"`、`targetSourceId`，使用静态 runtime，无交互规则或计数。用户在玩法属性中添加部件，部件保留自己的参数及几何信息，读取绑定实例的状态。允许同一玩法添加多个部件；复制时同步重建绑定。状态、说明和展示部件不播放玩法音效，也不重复处理礼物。

SDK 提供 `scene.lifecycle` 的开始／暂停／继续／停止／可见性／音量／尺寸／销毁回调。订阅者异常逐个隔离，并上报宿主；宿主只暂停报错来源，编辑器可重新加载，原计数保留。此机制处理脚本异常，不代表 iframe 独占 CPU／GPU，亦不保证自动恢复所有渲染进程崩溃。

快照的 `playbackRevision` 仅在播放时间轴或控制状态改变时更新。视频插件据此区分播放操作和尺寸、可见性等展示通知；同一播放版本不重复跳转进度或调用播放，避免拖动和缩放打断视频。

`scene.onEvent` 与 `scene.onAction` 初次订阅不补播历史。每个运行实例保存单调递增序号与最近 256 条事件／动作；快照保持权威状态，超出保留窗口时 `onGap` 明确通知缺口。插件须用最新状态重建画面，或合并特效，不能自行按收到的动画回调累加业务计数。SDK 不承诺重播任意长时间历史；权威礼物去重与事务计数仍由宿主维护。

“设置 → 导出诊断报告”输出版本、插件／来源状态及进程 CPU／内存信息，不含 Cookie、文件路径、用户设置或聊天／礼物明细。不会自动上传。
