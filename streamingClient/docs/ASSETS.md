# 素材与数据来源

源码包只保留当前构建使用的素材。没有把历史生成过程、私人参考图、旧影片或作者本机验收截图作为发行素材。

## 原创图片与程序化图形

- `../plugins/dragon/assets/skins/` 的三张 PNG 是本项目生成并整理的 AI 美术：上方仙山对峙图，以及猪大、恶龙的独立数值面板背景。当前插件使用静态图，未包含旧竖版战斗影片。
- 锁链材质由 `scripts/chain-art.ts` 生成，缝纫机、任务条、基础来源及实验性世界使用项目内 SVG、Canvas 或 CSS 绘制。
- 上述项目素材随本仓库按 MIT 提供；AI 生成的美术不保证独占性。品牌名称、外部平台标识和第三方内容的权利不因代码许可而转移。

## 原创拟音

锁链金属碰撞与消融声音由 `scripts/chain-foley.ts` 程序化合成；生成参数、规格与 SHA-256 在 `games/chain/audio/source/provenance.json`。缝纫机追加／加工／完成音效由 `scripts/sewing-foley.ts` 合成，成品位于 `../plugins/live-modes/audio/`。

当前音效不使用录音采样、人声、外部音乐或 SoundFont，按项目 MIT 许可提供。可运行 `npm run audio:generate` 重建。自动音频测试验证格式、幅度与触发逻辑，不代替真实设备试听。

## 礼物目录与图标

`client/src/main/data/` 保存礼物目录快照和来源信息，供编号、名称及目录回退使用。直播间同步的礼物信息优先于快照，平台可以调整编号、名称和可用范围。

礼物名称、图标 URL 和运行时下载的图标属于平台提供的数据及素材，不属于本项目原创 MIT 美术。仓库不包含客户端按需下载的图标缓存。使用者应遵守平台适用规则，不应把目录快照视为永久完整的官方 API。
