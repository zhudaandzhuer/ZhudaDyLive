# 架构与模块边界

工作台负责场景、媒体和全局事件；插件负责声明玩法和显示内容。编辑器、输出窗口和手机预览消费同一份宿主状态。

## 数据流

1. Electron 主进程在本机管理抖音登录和采集会话。
2. `packages/core` 解码消息、去重并计算礼物连击新增量。
3. 场景宿主让所有互动图层待命；礼物和全局热键统一分发到匹配图层。
4. React 编辑器通过受控 preload / IPC 编辑场景；插件来源在沙盒 iframe 中运行。
5. 独立输出和局域网预览读取同一份状态，不获得桌面管理 API。

## 代码职责

| 位置                           | 职责                                      |
| ------------------------------ | ----------------------------------------- |
| `packages/contracts/src/`      | IPC、事件、插件和场景类型与校验           |
| `packages/core/src/`           | 协议、SQLite、ZIP 校验和插件数据迁移      |
| `client/src/main/collector.ts` | 本机直播页面与采集会话                    |
| `client/src/main/scenes/`      | 场景库、媒体、事件分发、热键和手机分享    |
| `client/src/main/plugins/`     | 本机 ZIP 扫描、安装、更新、回退和资源协议 |
| `client/src/renderer/`         | 观测、插件区、场景编辑与输出              |
| `packages/plugin-sdk/src/`     | 插件 RPC、场景订阅、事件游标和声音中继    |

## 插件规则

插件只从本机插件区读取。ZIP 必须包含 `plugin.json` 和 `index.html`；工作台会校验路径、大小、哈希、权限和场景来源。场景固定插件版本，更新后可在暂停状态应用新版或回退。客户端内置的局域网手机预览只在用户主动开启时监听本机端口，关闭工作台即停止。

插件 iframe 没有 Node.js、Electron preload、文件系统或任意网络权限。文件夹访问必须由用户逐个选择。插件数据按插件 ID 独立保存。

## 持久化与恢复

场景自动保存，支持多个主播场景切换、导入导出和本机媒体缓存。重新打开、下播、换房或新连接批次会清除旧互动 runtime 和事件去重边界，插件重新待命。场景包不包含登录会话、Cookie、插件 ZIP 或礼物记录。
