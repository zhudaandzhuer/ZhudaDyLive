# 发布前检查

当前主程序 **0.3.1**，插件 SDK **1.0.0**，仍为预发布阶段。以下是每次发行需要重新确认的条件，不是未经执行的通过声明。

## 源码

- [ ] 干净环境 `npm ci`、`npm run check`、`npm run build` 通过。
- [ ] Linux、Windows、macOS 的 GitHub Actions 实际通过。
- [ ] 源码包不包含本机配置、密钥、账号会话、数据库、日志或应用安装包。
- [ ] README、CHANGELOG、协议、素材来源与第三方许可证和当前实现一致。
- [ ] 插件版本、主程序版本、最低能力及 SDK 兼容要求一致。

## 服务与桌面包

- [ ] 生产插件签章密钥、备份和恢复流程已配置。
- [ ] 生产构建指向正确服务，`development: false`，不含测试入口和多人实验。
- [ ] 客户端无服务时仍能启动；抖音断线、重连与本机插件区异常的行为已验证。
- [ ] macOS / Windows 原生运行，场景媒体、声音、系统选择器、热键和实际捕捉已验证。
- [ ] 真机扫码预览、音频手势、断线和分享撤销已验证。
- [ ] 发行包包含完整应用目录、项目许可与依赖声明，附版本和 SHA-256。
- [ ] 签名、公证、安装器或系统拦截提示的实际状态已明确说明。

## 插件与真实直播

- [ ] 新版本有独立 ZIP，不覆盖旧版；旧场景继续固定旧版。
- [ ] 安装、权限变化、数据迁移、失败回退和场景升级已验证。
- [ ] 快速连续礼物、去重、完成后继续接收、特效中断及多输出一致已验证。
- [ ] 真实直播礼物与份数核对，以及复杂场景长时间运行已验证。

主程序当前手动更新。SDK 不允许任意插件代码在主进程执行，也不保证抵挡修改客户端。生产签章由各发行者配置，仓库不附带生产密钥、账号或可用性承诺。

具体命令见 [发行流程](RELEASING.md)；测试边界见 [验收说明](ACCEPTANCE.md)。
