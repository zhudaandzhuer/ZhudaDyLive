# 猪大直播工作台

本仓库已按职责整理：

- [`streamingClient/`](streamingClient/)：猪大直播桌面工作台、共享套件、游戏、测试与开发文档。
- [`plugins/`](plugins/)：所有内置与可部署插件，包括 [`plugin.crazysea`](plugins/crazysea/)。

开发与构建请进入 `streamingClient/`：

```sh
cd streamingClient
npm ci
npm run setup
npm run dev
```

项目许可证见 [`streamingClient/LICENSE`](streamingClient/LICENSE)。
